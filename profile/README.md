# Zeddius

Personal life software that I am building for myself, starting with health. It is in progress, and the code is public.

The long-term idea is a socially-backed, identity-based behavior management platform. Right now it is just the tools I use every day. The write-up is on my site, and zeddius.com is an under-construction page.

[Project write-up](https://joshuasells.com/projects/zeddius) · [API docs](https://api.zeddius.com/docs) · [zeddius.com](https://zeddius.com)
